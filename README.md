## About

I build software from first principles: I implement the mechanism before I adopt the abstraction. I wrote a reverse-mode autograd engine and trained a neural network on it, and I implemented core machine learning algorithms from scratch in NumPy before using library versions. That gives me a working model of what optimizers, loss functions, and gradients do when training behaves badly.

My focus is AI and ML, backed by engineering breadth. I have shipped a full-stack application with a relational database, a REST API, and automated tests, so I can take a model from experiment to a service others can use. I work in C++ and Python, take part in competitive programming contests including Codeforces and IEEE Xtreme, and have coursework in numerical analysis, formal languages and automata, and image processing. I'm now extending that foundation toward transformers and LLM-based systems.

### PureGrad: Backpropagation From First Principles
`Python`

- Implemented a scalar autograd engine using reverse-mode differentiation over a dynamically built computation graph.
- Built the backward pass on a topological ordering of the graph, so gradients propagate correctly through shared nodes.
