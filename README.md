## 🚀 Selected Engineering Work

### 🖥️ ParcIT: IT Asset Management Platform
`React` `FastAPI` `PostgreSQL`

- Modeled a relational PostgreSQL schema and exposed it through a FastAPI REST backend.
- Implemented bcrypt password hashing and traced a bcrypt/passlib incompatibility to its root cause.
- Covered the backend with 8 automated tests and documented the design and delivery in a LaTeX report.

### 🔬 PureGrad: Backpropagation From First Principles
`Python`

- Implemented a scalar autograd engine using reverse-mode differentiation over a dynamically built computation graph.
- Built the backward pass on a topological ordering of the graph, so gradients propagate correctly through shared nodes.
- Trained a small multi-layer perceptron with gradient descent on top of it, with no ML framework involved.

### 📐 ML Algorithms From Scratch
`Python` `NumPy`

- Implemented core supervised-learning algorithms using vectorized NumPy: cost functions, gradient computation, and gradient-based optimization.
- Worked at the array level instead of calling library estimators, to see how learning rate, feature scaling, and regularization affect convergence.

### ⚽ Football Match Outcome Predictor
`Python`

Supervised classification pipeline on tabular historical match data, reaching **90.31% accuracy**.
